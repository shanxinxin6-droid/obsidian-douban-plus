# 配置迁移与旧笔记补全

1. 安装 Douban Plus 后，点击看板“管理工具”或插件设置“高级”标签页中的“导入原配置”，两个入口功能相同。可以点击“读取当前库的旧配置”，读取当前笔记库配置目录下 `plugins/obsidian-douban-plugin/data.json`；也可以选择旧插件的 JSON 配置文件，或在输入框粘贴 JSON。未找到旧插件时仍可选择文件或粘贴内容。
2. 点击“预览配置”，查看将导入的模板路径、输出路径、字段与同步历史。预览不会保存设置，修改内容后需重新预览。点击“确认导入”后，替换 Plus 中对应的设置并重建索引。原文件保留，登录凭据不导入，已有 Plus 登录信息与看板布局保留。模板、笔记和附件不会复制到新库；跨库导入时需要自行复制文件并核对路径。首次使用 Plus 且没有旧配置时无需执行此操作。
3. 两个插件可同时安装，执行同步时建议只启用一个，避免同时写同一批笔记。

## 补全缺失属性

在插件设置的“高级”标签页找到“迁移／修复笔记属性”，点击“打开修复工具”。看板的“管理工具 → 迁移与修复”也保留同一功能入口。Plus 新导入的笔记无需执行该操作。扫描原输出目录及额外目录；在“扫描范围与字段映射”中修改目录或旧字段名称后，点击“重新扫描”。

默认只显示“待补全”。“需处理”集中显示缺少可靠链接、多个链接、重复关联或无效 YAML 的笔记，这些文件不可直接勾选写入；“无需补全”表示基础属性无实际变化，并不表示封面、评分等资料全部已知。每篇笔记显示新增／调整数量和“属性、现在、补全后”对照；关联标记与暂无信息的属性收进展开项。未知内容保持空值，不虚构日期或评分。属性值相同而 YAML 排版或注释不同，不会列为待补全，也不会重写文件。

已关联笔记若只是缺少无法从本地恢复的空封面、未评分等可选属性，也不列为待补全；需要实际获取资料时使用“刷新属性”。“需处理”中的普通笔记或同步报告可忽略，它们没有可靠标识，插件不会将其自动关联到豆瓣条目。

预览不会写入笔记，默认不选中任何文件。查看条目标识、拟新增属性和识别问题，再勾选文件执行“补全所选笔记”。正文及其他自定义属性保留。写入前备份，并再次核对文件是否与预览时相同；如果发生变化，重新预览。

电影域名链接不能单独证明是电影还是电视剧。预览会标记“影视类型待确认”，可以展开对应笔记的“关联与联网补全”，点击“联网获取预览”取得结构化数据后重新预览；联网获取本身不会写入笔记，仍需勾选并补全。如果先离线补全，类型保持 `unknown`，之后可用“刷新属性”确认类型。

缺少 ID 或可靠链接时不会按标题匹配。输入完整豆瓣条目链接，点击“预览关联”，或先在原搜索窗口选择条目。多个链接、身份冲突、重复关联和非法 YAML 显示原因并跳过。重复文件应先由用户处理，避免自动覆盖错误文件。

“选择／取消此分类待补全项”作用于当前分类全部待补全项，包括分页尚未展开的笔记；可逐篇勾选，只写入已选笔记。再次执行前重新扫描。已完整的属性不会重复添加；既有有效身份字段会保留，远程身份不一致则拒绝写入。补全完成显示成功与失败数量及文件原因；成功项转入“无需补全”，失败项进入“需处理”。

## 恢复

备份保存在当前笔记库配置目录的 `plugins/obsidian-douban-plus/backups`，每条记录包含原文件路径、补全前后内容和时间。此目录不参与源码版本管理，随笔记库备份一起保存。

在补全窗口点击“恢复备份”→“查看恢复预览”。界面并列展示当前内容与将恢复的内容；补全后又编辑过的笔记会明确提示。确认“恢复这个备份”才写入，并再次核对当前内容。文件已移动或删除时不会按旧路径创建文件；先恢复对应路径或手动取出备份内容。

## 日常使用

默认同步和“刷新属性”仅修改插件管理的属性，自己写的正文继续保留。“强制覆盖”会重新生成正文，只在确实需要重新套用模板时开启。非法 YAML 先手动修复；请求失败后本地数据仍可浏览，稍后重新选择范围重试。

完整属性表见 [开发说明](DEVELOPMENT.md)。历史笔记中原本不存在且无法从链接推断的字段，需要远程获取或人工关联，不能靠模板解析凭空恢复。
