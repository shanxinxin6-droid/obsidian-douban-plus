# Douban Plus 0.1.0 — 首个公开测试版

基于 Wanxp/obsidian-douban，由 shanxinxin6-droid 独立维护，采用 GPLv3 许可证。

本版本新增本地豆瓣看板，提供卡片、封面与收藏时间线三种布局，以及搜索、筛选、分组和笔记访问。整篇导入自动补充看板属性；再次同步默认刷新属性并保留正文。旧配置与旧笔记提供预览导入、补全、备份和恢复。

## 安装

- **BRAT**：添加 `https://github.com/shanxinxin6-droid/obsidian-douban-plus`，选择 `0.1.0` 并安装，再在 Obsidian 中启用 Douban Plus。
- **手动**：下载下方 `obsidian-douban-plus-0.1.0.zip`，解压出插件文件夹，放入笔记库的 `.obsidian/plugins/`。不要下载 Source code ZIP 作为安装包。
- 更新时保留现有 `data.json` 与 `backups`，批量修改前备份笔记库。与原插件共用输出目录时，只启用一个执行同步。

## 验证范围

基础看板与部分迁移流程已在 Windows 桌面 Obsidian 1.14.4 验证。完整真实账号登录、搜索导入与收藏同步仍待验收；联网自动测试使用模拟响应。清单最低版本 1.4.4 与移动端尚未实机验收。此版本用于桌面试用与反馈。

详见 [README](https://github.com/shanxinxin6-droid/obsidian-douban-plus#readme) 和 [测试报告](https://github.com/shanxinxin6-droid/obsidian-douban-plus/blob/0.1.0/docs/TEST_REPORT.md)。
